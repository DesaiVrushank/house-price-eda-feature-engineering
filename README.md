# House Price Analysis Using EDA & Feature Engineering

Exploratory Data Analysis (EDA) and feature engineering project on house price data, including data cleaning, missing value and duplicate handling, outlier analysis, data visualization, correlation analysis, and creation of meaningful features.

## Description

This project focuses on analyzing house characteristics to understand their relationship with house prices. Exploratory Data Analysis (EDA) is performed to identify data quality issues and discover useful patterns in the dataset.

The project includes data inspection, missing value analysis, duplicate detection, invalid value identification, outlier analysis, data visualization, correlation analysis, and data cleaning.

Feature engineering is performed by creating `price_per_sqft` and `sqft_per_bedroom`. Finally, `price_lakh` is separated as the target variable from the input features.

## Dataset

The dataset contains the following features:

- `area_sqft`
- `bedrooms`
- `age_years`
- `distance_city_km`
- `price_lakh`
