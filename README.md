# house-price-eda-feature-engineering
Exploratory Data Analysis (EDA) and feature engineering project on house price data, including data cleaning, missing value and duplicate handling, outlier analysis, data visualization, correlation analysis, and creation of meaningful features.

# House Price Analysis Using EDA

## Description

This project focuses on analyzing house characteristics to understand their relationship with house prices. Exploratory Data Analysis (EDA) is performed on the dataset to identify data quality issues and discover useful patterns.

The project includes data inspection, missing value analysis, duplicate detection, invalid value identification, outlier analysis, data visualization, correlation analysis, and data cleaning.

Feature engineering is also performed by creating `price_per_sqft` and `sqft_per_bedroom`. Finally, `price_lakh` is separated as the target variable from the input features.

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Dataset

The dataset contains:

- `area_sqft`
- `bedrooms`
- `age_years`
- `distance_city_km`
- `price_lakh`
